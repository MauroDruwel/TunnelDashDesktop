# Agent Guidelines & Repository Architecture

This file provides context, commands, and operational guardrails for AI coding assistants (Antigravity, Cursor, Claude Code, Copilot, Codex) working on **TunnelDashDesktop**.

---

## 🧭 Project Overview

**TunnelDash** is a desktop sidekick for Cloudflare Tunnels and Zero Trust SSH access, built with:
- **Frontend**: React 18, TypeScript, Vite, CSS (vanilla dark/light theme).
- **Desktop Core**: Tauri v2, Rust (2021 edition), Tokio, OS Keychain integration.
- **Standards**: Strictly adheres to the **[Mauro Quality Gate (MQG)](https://github.com/MauroDruwel/quality-gate)**.

---

## 🛠️ Developer & Agent Toolchain

| Action | Command | Notes |
|---|---|---|
| **Install Dependencies** | `pnpm install` | Prefer `pnpm` across all frontend commands. |
| **Frontend Build** | `pnpm build` | Runs `tsc && vite build`. |
| **Native App Build** | `pnpm tauri build` | Bundles native desktop application (`.app` / `.dmg` on macOS, `.msi` on Windows). |
| **Development Server** | `pnpm tauri dev` | Starts Vite dev server + Tauri native desktop window. |
| **Frontend Unit Tests** | `pnpm test` | Runs Vitest test suite (`src/**/*.test.ts`). |
| **Rust Backend Tests** | `cargo test --manifest-path src-tauri/Cargo.toml` | Runs Rust unit & integration tests. |
| **Typecheck** | `pnpm typecheck` | Strict `tsc --noEmit` validation. |
| **Lint** | `pnpm lint` | Runs ESLint. Must pass with zero warnings. |
| **Quality Gate Audit** | `python3 /path/to/quality-gate/scripts/audit_project.py .` | Audits governance, architecture, CI/CD, and tests. |

## 🔐 Architectural Rules & Invariants

### 1. SSH Configuration Management (`~/.ssh/config`)
- **Delimited Markers**: All TunnelDash-managed entries in `~/.ssh/config` MUST strictly remain between:
  ```sshconfig
  # >>> TunnelDash managed SSH configuration >>>
  # Automatically generated by TunnelDash. Any manual changes inside this block will be overwritten.
  ...
  # <<< TunnelDash managed SSH configuration <<<
  ```
- **Never Modify External Entries**: Any user configurations before or after the delimiter markers must be preserved untouched.
- **File Permissions**: Always ensure `0o700` for `~/.ssh` and `0o600` for `~/.ssh/config` on Unix/macOS.
- **Cross-Platform**: Support `$HOME/.ssh/config` (macOS/Linux) and `%USERPROFILE%\.ssh\config` (Windows).

### 2. Credential Storage & Security
- **Never Store Secrets in Plaintext**: Plaintext passwords and private key passphrases must NEVER be written to `~/.ssh/config`, configuration files, logs, or terminal output.
- **Keychain Storage**:
  - macOS: Apple Keychain Services (`security add-generic-password`) under service `be.maurodruwel.tunneldash`.
  - Windows/Linux: System credential manager via the Rust `keyring` crate.

### 3. IPC & Tauri Commands
- All Rust-to-Frontend Tauri commands are registered in `src-tauri/src/lib.rs`.
- When returning errors from Tauri commands, return descriptive strings (`Result<T, String>`) so the frontend surfaces user-friendly error banners.
